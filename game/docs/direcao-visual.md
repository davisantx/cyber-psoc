# Direção visual do menu — fundo abstrato

A tela inicial de CYBER apresenta somente o nome do projeto, as opções do menu e um fundo abstrato. Não há cenário, personagens, objetos ou mensagens que sugiram o enredo. Essa escolha mantém a abertura neutra enquanto a narrativa é definida pela equipe.

## Composição

- Título e opções centralizados, em uma única coluna.
- Fundo feito com gradientes suaves de cor escura. Não usa imagem raster ou elementos figurativos.
- Destaque visual discreto para a opção ativa e foco de teclado visível.
- Aviso curto de desenvolvimento para que “Novo Jogo” não sugira conteúdo já concluído.
- Adaptação para tela de computador, projetor e celular, com preferência por movimento reduzido respeitada.

## Histórico

As tentativas anteriores de cafeteria e sala de aula foram movidas para `docs/visual-history/`. A interface atual não carrega esses arquivos. A origem das imagens geradas está registrada em `../../registro-prompts.md`.
